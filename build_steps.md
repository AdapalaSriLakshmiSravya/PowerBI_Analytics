# Build Steps (summary)

1. Paste queries from `powerquery/` (update path), Close & Apply.
2. Add calculated columns from `dax/calculated_columns.dax`; set sort-by columns for the bands.
3. Create `_Measures` and paste `dax/measures.dax`; format measures.
4. Build 6 pages and the Employee Detail drill-through per `report_pages_visuals.md`.
5. Sync core slicers (View > Sync slicers).
6. Run `validation_checklist.md`, apply a theme, export screenshots, save `.pbix` in `../powerbi/`.
7. Prepare a 5-10 minute walkthrough: workforce overview, attrition concentration, associated factors, compensation/satisfaction/travel/overtime, promotion/retrenchment, exceptions to validate, HR actions to investigate.
